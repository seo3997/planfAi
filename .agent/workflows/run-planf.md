description: 로컬 개발 서버 실행 (planfAi)
---

명령어 "**로컬서버에서 planf 실행해**" 또는 "**개발서버 실행해**"가 입력되면 다음 단계를 수행합니다.

// turbo-all

1. **클라이언트 코드 분석**: `src/main/resources/static` 내의 HTML 및 JavaScript 파일을 분석하여 API 요청 구조 및 비즈니스 로직을 파악합니다.
2. **프로젝트 루트 디렉토리 이동**: `/Users/soo/Documents/AiWork/planfAi/development-source`로 이동합니다.
3. **서버 실행**: `./run.sh start` 명령을 실행합니다.
4. **결과 확인**: 빌드 및 실행 로그를 실시간으로 확인하여 서버가 정상적으로 구동되고 브라우저가 열리는지 확인합니다.
