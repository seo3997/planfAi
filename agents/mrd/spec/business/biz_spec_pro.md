# [PRD] 소상공인 재무 시뮬레이션 시스템 상세 설계서 - 전문가 모드 (Expert Mode)

## 1. 기본 환경 설정 (Basic Setup)

모든 재무 계산의 기준점(Baseline)을 정의합니다.

- **업종 선택 (industryCd)**: 1:제조업, 2:소매업, 3:외식업, 4:시설서비스업, 5:용역서비스업
- **매출 계산 모드 (saleMode)**: 1: 일 판매량 기준, 2: 월 판매량 기준
- **영업 일수 (workDay)**: 월평균 실제 가동일 (1~31일)
- **월 목표 이익 (monTargetPrice)**: 사업자가 달성하고자 하는 세전 순이익 목표액

## 2. 예상 매출액 계획 (Sales Plan)

- **계산 로직**:
  - **월 매출액 (S_month)**: 일 판매 기준(`단가 * 일 판매량 * 영업일수`) 또는 월 판매 기준(`단가 * 월 판매량`)
  - **년 매출액 (S_year)**: `S_month * 12`
- **연도별 매출 확장 (2, 3차년도)**: 증감율 모드(자동 계산) 또는 직접 입력 모드 선택 가능
- **시스템 연동**: 합계된 월 매출액은 모든 경비 계산의 모수가 됨

## 3. 재료비 및 매출원가 계획 (COGS Plan)

### 3.1. 재료비 (Variable Costs)

- **메뉴별 재료비율 (costRate, %)**: 각 메뉴별 매출액 대비 원가 비중
- **연도별 재료비**: 증감율(`costAmtRate`)에 따라 `costRate`와 `costAmt`가 자동 산출됨

### 3.2. 매출원가 명세서 (Cost of Goods Sold)

제조업 (industryCd=1):

- 당기제품제조원가 = 재료비 + 노무비(제조) + 제조경비
- 당기매출원가 = 기초재고 + 당기제품제조원가 - 기말재고
  비제조업 (그 외 업종):
- 당기매출원가 = 기초재고 + 당기상품매입액(재료비) - 기말재고

## 4. 인건비 계획 (Labor Cost Plan)

- **부문 분류**: 제조부문(제조원가 귀속), 판매관리부문(판관비 귀속)
- **생산성 지표**: 인건비 비율 및 1인당 매출액/인건비 산출

## 5. 투자 및 감가상각 계획 (Investment Plan)

- **상각 로직**: `investYn = 'Y'`인 경우 `투자금액 / (상각년수 * 12)`를 통해 월 감가상각비 생성
- **데이터 매핑**: 제조/판매 부문 선택에 따라 해당 부문 비용으로 귀속

## 6. 자금조달 계획 (Financing Plan)

- **자기자금 (equity)** / **타인자금 (debt)** 구분
- **이자 비용**: `차입금액 * (이자율 / 100)` (소수점 반올림)

## 7&8. 경비 계획 (Expense Plan: Manufacturing & SGA)

항목별로 4가지 기준 중 하나를 선택하여 자동 계산합니다.

1. **매출액 대비 %**: `매출합계 * 적용값(%)`
2. **월정액**: 고정 금액 입력
3. **인건비 대비 %**: `해당부문 인건비 * 적용값(%)`
4. **기준액 대비 %**: `감가상각 대상금액 * 적용값(%)`

## 9. 재무제표 시뮬레이션

### 9.1. 연도별 손익계산서 (P&L)

- **매출총이익**: `매출액 - 매출원가(재료비 등)`
- **영업이익**: `매출총이익 - 판매관리비(감가상각비 포함)`
- **경상이익**: `영업이익 - 영업외비용(이자)`

### 9.2. 손익분기점 분석 (BEP)

- **변동비**: 재료비 + 매출연동형 경비
- **고정비**: 인건비 + 월정액 경비 + **감가상각비** + **이자비용**
- **BEP 매출액**: `고정비 / (한계이익률 / 100)` (한계이익률 = `(매출-변동비)/매출 * 100`)

## 10. 경영 진단 리포트 (Diagnosis)

### 10.1 업종별 표준 지표 (우수 기준)

| 지표명               | 산출 공식                      | 업종별 검토 기준                                      |
| :------------------- | :----------------------------- | :---------------------------------------------------- |
| **투자금액회전율**   | `연매출액 / 총투자금액`        | 제조(1.5), 소매(2.7), 음식(1.8), 시설(0.9) 이상       |
| **매출영업이익률**   | `영업이익 / 연매출액`          | 제조(10%), 소매(10.8%), 음식(16.2%), 시설(32.4%) 이상 |
| **총자산영업이익률** | `영업이익 / (총투자금액 / 12)` | 제조(2%), 타업종(2.7%) 이상                           |
| **인건비 비율**      | `총인건비 / 연매출액`          | 제조(15%), 소매(8.8%), 음식(22%), 시설(27.5%) 이하    |
| **1인당 월매출액**   | `월매출액 / (종업원수 / 12)`   | 제조(1,000만), 소매(2,280만), 외식(900만) 이상        |
| **임차료 비율**      | `월임차료 / 월매출액`          | 제조(5%), 소매(8.8%), 외식(11%), 시설(16.5%) 이하     |
| **자기자본비율**     | `자기자본 / 총자산`            | 전 업종 50% 이상 권장                                 |
| **손익분기점률**     | `BEP매출액 / 실제매출액`       | 제조(66%), 소매(66%), 외식(73.6%), 시설(66%) 이하     |

## 13. 대시보드 상세 설계 및 정합성 검증

### 1. 상단 핵심 요약 (Key Metrics)

- **실질 영업이익**: 매출에서 재료비와 판관비(상각비 포함)를 모두 뺀 결과물 노출
- **BEP 달성률**: `(현재 매출액 / BEP 매출액) * 100`. 100% 도달 시 영업이익은 반드시 **0원**임
- **추가 필요 매출액**: 현재 매출이 BEP 미달 시, 본전 달성을 위해 즉시 추가해야 할 매출액 노출

### 2. 비용 구조 시각화 (Cost Breakdown)

- **변동비**: 재료비(매출원가)와 매출연동형 경비를 합산 노출
- **고정비**: 인건비, 임차료, 상각비에 **이자비용**을 포함하여 실질적 본전 기준 제시

### 3. 데이터 정합성 강제 규칙 (Validation)

- **재료비 우선 차감**: 모든 이익 산출의 최우선 단계는 매출액에서 재료비를 차감하는 것임을 강제함
- **Zero-Sum 검증**: 매출액 = BEP 매출액일 때 영업이익 0원 확인
- **표기 일치**: 연간 리포트 판관비 총액은 상각비를 포함해야 하며, UI 들여쓰기(`ㄴ`) 시 중복 차감 방지
- **상각비 동기화**: 월 대시보드 상각비는 연간 상각비 총액의 1/12과 일치해야 함
- **영업이익 vs BEP**: 영업이익(9.1)은 이자 제외, BEP(9.2) 산출 고정비에는 이자 포함 원칙 준수
