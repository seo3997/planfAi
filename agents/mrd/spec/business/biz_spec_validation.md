# [Verification Spec] 소상공인 재무 시뮬레이션 검증 명세서

## 1. 검증 개요

본 명세서는 [PRD] 전문가 모드 설계서를 바탕으로, 클라이언트 사이드에서 계산된 재무 데이터가 회계 원칙 및 업종별 표준 지표에 부합하는지 검증하기 위해 작성되었습니다.

---

## 2. 부문별 비용 귀속 검증 (Cost Allocation)

에이전트는 모든 인건비(`job`)와 경비(`expense`)가 부문에 따라 정확한 계정으로 처리되는지 확인해야 합니다.

| 입력 부문        | 데이터 필드  | 반영 계정 (Accounting) | 최종 목적지         |
| :--------------- | :----------- | :--------------------- | :------------------ |
| **제조부문**     | `production` | 노무비 / 제조경비      | **매출원가(COGS)**  |
| **판매관리부문** | `sales`      | 급여 / 판매비          | **판매관리비(SGA)** |

---

## 3. 매출원가(COGS) 연산 로직 검증

업종(`industryCd`)에 따른 원가 산출 공식의 분기 처리를 검증합니다.

- **제조업 (`industryCd: 1`)**:
  - `당기제품제조원가 = 재료비 + 노무비(제조) + 제조경비`
  - `당기매출원가 = 기초재고 + 당기제품제조원가 - 기말재고`
- **비제조업**:
  - `당기매출원가 = 당기상품매입액(재료비)`

---

## 4. 경영 진단 지표 및 업종별 기준치 (8대 지표)

에이전트는 계산된 결과값이 아래 업종별 기준치와 비교되어 정확한 판정(우수/보통/주의)을 내리는지 검증합니다.

| 지표명               | 산출 공식                      | 업종별 우수 기준                                                            |
| :------------------- | :----------------------------- | :-------------------------------------------------------------------------- |
| **투자금액회전율**   | `연매출액 / 총투자금액`        | 제조(1.5), 소매(2.7), 음식(1.8), 시설(0.9), 기술(1.4) **이상**              |
| **매출영업이익률**   | `영업이익 / 연매출액`          | 제조(10%), 소매(10.8%), 음식(16.2%), 시설(32.4%), 기술(21.8%) **이상**      |
| **총자산영업이익률** | `영업이익 / (총투자금액 / 12)` | 제조(2.0%), 타업종(2.7%) **이상**                                           |
| **인건비 비율**      | `총인건비 / 연매출액`          | 제조(15%), 소매(8.8%), 음식(22%), 시설(27.5%), 기술(44%) **이하**           |
| **1인당 월매출액**   | `월매출액 / (종업원수 / 12)`   | 제조(1천만), 소매(2.28천만), 외식(900만), 시설(720만), 기술(450만) **이상** |
| **임차료 비율**      | `월임차료 / 월매출액`          | 제조(5%), 소매(8.8%), 외식(11%), 시설(16.5%), 기술(11%) **이하**            |
| **자기자본비율**     | `자기자본 / 총자산`            | 전 업종 **50% 이상** 권장                                                   |
| **손익분기점률**     | `BEP매출액 / 실제매출액`       | 제조(66%), 소매(66%), 외식(73.6%), 시설(66%), 기술(80%) **이하**            |

## 5. 핵심 보정 및 데이터 매핑 규칙

에이전트는 다음 수식의 기술적 구현을 집중적으로 체크합니다.

- **연간 데이터 보정**: `총자산영업이익률`과 `1인당 월매출액` 산출 시 분모를 반드시 **12로 나누는 로직**이 포함되어야 합니다.
- **총자산 정의**: `비유동자산(투자금-누적상각) + 유동자산`으로 계산되는지 확인합니다.
- **종업원수**: `job.production` 및 `job.sales`의 모든 `jobCnt`를 합산하여 분모로 사용합니다.

---

## 6. 에이전트 검증 액션 지시 (Action)

1. **소스 분석**: `development-source`에서 재무 연산 및 진단 리포트 생성을 담당하는 JS/TS 모듈을 식별하십시오.
2. **데이터 시뮬레이션**: 위 명세서의 공식을 적용하여 테스트 케이스를 실행하고, 반환된 JSON의 `summary` 및 `diagnosis` 객체값이 명세서의 기대값과 일치하는지 대조하십시오.
3. **결과 리포트**: 불일치 사항 발견 시, 어떤 수식 혹은 업종별 매핑에서 오류가 발생했는지 구체적인 코드 위치와 함께 리포트하십시오.
